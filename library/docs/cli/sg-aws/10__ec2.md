# `sg aws ec2` — EC2 Instance Management

Primitives for listing, describing, launching, and lifecycle-managing EC2 instances.
The container-hosts primitive (v0.2.30) and the instance-sizing measurement programme (v0.2.30) sit on top of this layer.

## Mutation gate

```bash
export SG_AWS__EC2__ALLOW_MUTATIONS=1   # required for create, start, stop, terminate, tags --add/--remove/--clear
```

Read-only verbs (`list`, `describe`, `ssh-info`, `tags` view, `instance-types`, `pricing`, `wait`) never require a gate.

---

## Verbs

### `list`

```bash
sg aws ec2 list                                        # all instances (all states)
sg aws ec2 list --state running                        # filter by state: running, stopped, etc.
sg aws ec2 list --prefix dev-                          # filter by Name tag prefix
sg aws ec2 list --tag sg:owner=alice                   # filter by arbitrary tag K=V
sg aws ec2 list --state running --json                 # JSON output
```

### `describe`

```bash
sg aws ec2 describe i-1234567890abcdef0               # by instance ID
sg aws ec2 describe my-server                          # by Name tag (exact or prefix)
sg aws ec2 describe my-server --json
```

Returns: instance ID, type, AMI, state, networking, key pair, VPC/subnet, architecture, IAM profile, tags, security groups.

### `ssh-info`

```bash
sg aws ec2 ssh-info i-1234567890abcdef0
sg aws ec2 ssh-info my-server
```

Prints the public DNS/IP, key name, and suggested `ssh` command. The key itself is never stored — retrieve from vault.

### `tags`

```bash
sg aws ec2 tags my-server                              # view current tags
sg aws ec2 tags my-server --json

# mutations (require SG_AWS__EC2__ALLOW_MUTATIONS=1)
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 tags my-server --add env=prod --yes
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 tags my-server --remove env --yes
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 tags my-server --clear --yes
```

`--add` and `--remove` are repeatable. `--clear` removes all tags first, then `--add` tags are applied.

### `instance-types`

```bash
sg aws ec2 instance-types                              # all types in current region
sg aws ec2 instance-types --family t3                  # filter by family prefix
sg aws ec2 instance-types --json | jq length
```

### `pricing`

```bash
sg aws ec2 pricing t3.micro
sg aws ec2 pricing m5.large --region eu-west-1
sg aws ec2 pricing t4g.nano --json
```

Returns per-hour and per-second on-demand Linux prices. AWS Pricing API always queried in `us-east-1` regardless of configured region.

### `create`

```bash
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 create \
    --name  dev-host-01 \
    --instance-type t3.micro \
    --ami ami-0abcdef1234567890 \
    --key-pair my-keypair \
    --subnet subnet-0123456789abcdef0 \
    --sg sg-0123456789abcdef0 \
    --tags env=dev,team=platform \
    --yes

# Waits for running state by default. Disable with --no-wait.
# sg:managed-by, sg:surface, sg:verb, sg:created-by, sg:created-at tags are applied automatically.
```

### `start`

```bash
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 start my-server
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 start my-server --yes   # skip confirmation
```

### `stop`

```bash
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 stop my-server
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 stop my-server --yes
```

Stops a running instance; preserves EBS volumes.

### `terminate`

```bash
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 terminate my-server
SG_AWS__EC2__ALLOW_MUTATIONS=1 sg aws ec2 terminate my-server --yes
```

**Irreversible.** Terminates the instance.

### `wait`

```bash
sg aws ec2 wait my-server --state running
sg aws ec2 wait my-server --state stopped --timeout 120
```

Polls until the instance reaches the target state or the timeout (default 300s) is exceeded. Exit code 1 on timeout.

---

## `<id-or-name>` resolution

All verbs that take an instance argument accept either:

- A bare **instance ID** (`i-xxxxxxxxxxxxxxxxx`) — passed through directly.
- A **Name tag value** — exact match first; falls back to prefix match. If more than one instance matches, an error lists both IDs so you can be more specific.
