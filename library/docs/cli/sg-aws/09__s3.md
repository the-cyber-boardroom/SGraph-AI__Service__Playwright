# 09 — `sg aws s3`

S3 object and bucket management — list, view, stat, presign, search, tail, edit, copy, move, delete, sync, and bucket operations.

**Mutation gate:** `SG_AWS__S3__ALLOW_MUTATIONS=1` required for `cp`, `mv`, `rm`, `sync`, `edit`, `bucket-create`.

---

## Command shape

```
sg aws s3 <verb> [args] [opts]
```

Read-only verbs run without any environment variable. Mutating verbs abort with a red panel unless the gate is set.

---

## `ls`

List all buckets (no argument) or list objects within a bucket/prefix.

```bash
sg aws s3 ls                                     # all buckets
sg aws s3 ls s3://my-bucket/                     # top-level objects + prefixes
sg aws s3 ls s3://my-bucket/logs/ --recursive    # all keys under prefix
sg aws s3 ls s3://my-bucket/logs/ --json         # JSON output
```

**Flags:** `--recursive` / `-r`, `--json`.

---

## `stat`

Full object metadata: size, ETag, storage class, content type, encryption, version ID.

```bash
sg aws s3 stat s3://my-bucket/data/report.json
sg aws s3 stat s3://my-bucket/data/report.json --json
```

**Flags:** `--json`.

---

## `view`

Format-aware rendering of object content.

| Format | Detection | Rendering |
|--------|-----------|-----------|
| JSON | `.json` extension or `{`/`[` sniff | Rich JSON syntax highlight |
| YAML | `.yml` / `.yaml` | Rich YAML highlight |
| Markdown | `.md` | Raw text |
| CSV/TSV | `.csv` / `.tsv` or comma sniff | Rich table (first 20 rows) |
| `.gz` | magic bytes `\x1f\x8b` | Transparent decompression; then re-detect |
| Binary | non-UTF-8 sniff | Metadata panel |
| Plain text | default | Raw |

```bash
sg aws s3 view s3://my-bucket/configs/agent.json
sg aws s3 view s3://my-bucket/data.csv
sg aws s3 view s3://my-bucket/logs/today.log.gz
sg aws s3 view s3://my-bucket/doc.json --raw    # skip detection, print raw
```

**Flags:** `--raw`, `--json` (JSON objects only).

---

## `cat`

Stream object content to stdout. Does not buffer the full object.

```bash
sg aws s3 cat s3://my-bucket/logs/today.log | grep ERROR
sg aws s3 cat s3://my-bucket/data.json | jq '.items | length'
```

---

## `head`

Print the first N lines of an object (default 10).

```bash
sg aws s3 head s3://my-bucket/logs/today.log
sg aws s3 head s3://my-bucket/logs/today.log --lines 50
```

**Flags:** `--lines` / `-n` (default 10).

---

## `tail`

Print the last N lines and optionally follow for new content.

```bash
sg aws s3 tail s3://my-bucket/logs/today.log
sg aws s3 tail s3://my-bucket/logs/today.log --lines 50
sg aws s3 tail s3://my-bucket/logs/today.log --follow      # poll every 5s
sg aws s3 tail s3://my-bucket/logs/today.log --since 1h    # since 1 hour ago
```

**Flags:** `--lines` / `-n` (default 100), `--follow` / `-f`, `--since` / `-s` (e.g. `5m`, `2h`, `1d`).

---

## `presign`

Generate a presigned download URL. Maximum TTL is 7 days (604 800 seconds).

```bash
sg aws s3 presign s3://my-bucket/report.pdf
sg aws s3 presign s3://my-bucket/report.pdf --ttl 86400    # 24-hour expiry
```

**Flags:** `--ttl` (seconds, default 3600, max 604800).

---

## `search`

Find objects whose keys match a glob or substring pattern.

```bash
sg aws s3 search s3://my-bucket/logs/ --pattern "*.log"
sg aws s3 search s3://my-bucket/ --pattern 2026-05 --json | jq length
```

**Flags:** `--pattern` / `-p` (required), `--json`.

---

## `cp`

Copy an object. Either side may be local or `s3://`.

```bash
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 cp local.json s3://my-bucket/uploaded.json
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 cp s3://my-bucket/a.json s3://my-bucket/b.json
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 cp s3://my-bucket/a.json ./local-copy.json
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 cp s3://my-bucket/a.json s3://my-bucket/b.json --yes
```

**Flags:** `--yes` / `-y` (skip confirmation).

---

## `mv`

Move an S3 object — copy then delete source. Both sides must be `s3://`.

```bash
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 mv s3://my-bucket/old.json s3://my-bucket/new.json --yes
```

**Flags:** `--yes` / `-y`.

```bash
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 rm s3://my-bucket/stale.log
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 rm s3://my-bucket/stale.log --yes
```

**Flags:** `--yes` / `-y`.

---

## `sync`

Sync a local directory to an S3 prefix (local → S3). Similar to `aws s3 sync`.

```bash
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 sync ./dist/ s3://my-bucket/releases/v1.2.3/ --dry-run
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 sync ./dist/ s3://my-bucket/releases/v1.2.3/ --yes
```

`--dry-run` prints the upload plan without executing. Run it first — it's the recommended first iteration.

**Flags:** `--dry-run`, `--yes` / `-y`.

---

## `edit`

vim round-trip editor for S3 objects.

1. Downloads the object to a temp file (respects `$SG_AWS__S3__EDIT_TMPDIR`).
2. Opens `$EDITOR` (default `vim`).
3. On exit:
   - No change detected → skips upload.
   - Changed + remote ETag unchanged → uploads with `IfMatch` conditional PUT.
   - Remote ETag changed (conflict) → refuses upload, saves your edits to `<tmpfile>.conflict`, exits 1.
4. Temp file is always cleaned up unless `--keep-local`.

```bash
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 edit s3://my-bucket/configs/agent.json
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 edit s3://my-bucket/configs/agent.json --editor nano
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 edit s3://my-bucket/configs/agent.json --keep-local
```

**Flags:** `--editor EDITOR`, `--keep-local`.


**Flags:** `--json`.

---

## `bucket-create`

Create an S3 bucket with sensible secure defaults:

- Public access fully blocked
- Versioning enabled

```bash
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 bucket-create sg-test-tmp-$(date +%s) --yes
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 bucket-create my-new-bucket --region eu-west-1 --yes
```

**Flags:** `--region` / `-r`, `--yes` / `-y`.

---

## Environment variables

| Variable | Purpose |
|----------|---------|
| `SG_AWS__S3__ALLOW_MUTATIONS` | Set to `1` to unlock mutating commands |
| `SG_AWS__S3__EDIT_TMPDIR` | Override temp directory for `edit` (default `/tmp`) |
| `EDITOR` | Editor binary for `edit` (default `vim`) |

## Source adapter

`S3__Source__Adapter` implements the shared `Source__Contract` so S3 buckets integrate with the observability surface (Slice H). Buckets appear as streams; `query()` filters by key pattern; `tail()` polls a log-like object.

```python
from sgraph_ai_service_playwright__cli.aws.s3.service.S3__Source__Adapter import S3__Source__Adapter
adapter = S3__Source__Adapter()
print(adapter.list_streams())    # → ['bucket-a', 'bucket-b', ...]
```
