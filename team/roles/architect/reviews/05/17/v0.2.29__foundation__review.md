### F-1 (HIGH) — Primitive consolidation is incomplete

**What landed:** `aws/_shared/primitives/Safe_Str__AWS__Account_Id.py` and `aws/_shared/primitives/Safe_Str__AWS__Region.py` were created with comments like *"consolidates copies in credentials/primitives/"*.

**What's missing:** the existing copies are still on disk and still being imported.

```
sgraph_ai_service_playwright__cli/credentials/primitives/Safe_Str__AWS__Account_Id.py    ← still here, different body
sgraph_ai_service_playwright__cli/ec2/primitives/Safe_Str__AWS__Account_Id.py            ← still here, different body
sgraph_ai_service_playwright__cli/aws/_shared/primitives/Safe_Str__AWS__Account_Id.py    ← canonical (NEW)

sgraph_ai_service_playwright__cli/credentials/primitives/Safe_Str__AWS__Region.py        ← still here
sgraph_ai_service_playwright__cli/observability/primitives/Safe_Str__AWS__Region.py      ← still here
sgraph_ai_service_playwright__cli/aws/_shared/primitives/Safe_Str__AWS__Region.py        ← canonical (NEW)
```

Net effect: we now have **three copies** of each primitive where the architect review said Foundation would leave **one**.

**Fix (choose one):**

- **(A) Migrate now (recommended).** Replace each old file with a one-line re-export shim:

  ```python
  # sgraph_ai_service_playwright__cli/credentials/primitives/Safe_Str__AWS__Account_Id.py
  # ═══════════════════════════════════════════════════════════════════════════════
  # SG Credentials — Safe_Str__AWS__Account_Id (re-export shim)
  # Canonical home: aws/_shared/primitives/. Shim kept for one release; drop v0.3.x.
  # ═══════════════════════════════════════════════════════════════════════════════
  from sgraph_ai_service_playwright__cli.aws._shared.primitives.Safe_Str__AWS__Account_Id import Safe_Str__AWS__Account_Id  # noqa: F401
  ```

  Run tests. If green, the migration is done — every old import path still works, every new caller can target the canonical home.

  Same shim for `Safe_Str__AWS__Region` at both old locations. Then check `Safe_Str__AWS__Role__ARN` (also exists in `credentials/primitives/`) — apply the same treatment.

- **(B) Document the deferral.** Update `02__common-foundation.md` §1.1 to say "Foundation creates the canonical home; v0.2.30 hygiene pack migrates existing duplicates." Less work, but every Slice now has to remember "import from `_shared` for new code, leave the old imports alone." Likely-to-be-forgotten.

**Recommendation:** (A). The re-export shims are cheap and don't break any test that's currently passing.

### F-2 (HIGH) — Per-surface service interface stubs are missing

**What the brief said** (`02__common-foundation.md §1.2`):

> | `aws/s3/` | `cli/Cli__S3.py` skeleton with locked verb names; **`service/S3__AWS__Client.py` interface stub**; per-class schema/enum/primitive stubs raising `NotImplementedError` | Slice A |

**What landed:** every surface has an empty `service/__init__.py` and nothing else under `service/`.

**Why this matters:** the orchestration plan said Slice H "consumes `S3__AWS__Client` and `CloudTrail__AWS__Client` — but that dependency is mediated through the Foundation-shipped interface stubs, so the slices run in parallel" (`03__sonnet-orchestration-plan.md §4`).

**Without those stubs Slice H is rebase-blocked until Slices A and F land.** That cuts the parallel critical path from ~5 calendar days back toward sequential.

**Fix:** add minimum interface stubs for the two clients Slice H needs:

```python
# sgraph_ai_service_playwright__cli/aws/s3/service/S3__AWS__Client.py
# ═══════════════════════════════════════════════════════════════════════════════
# SP CLI — S3__AWS__Client (Foundation interface stub)
# Real bodies owned by Slice A (v0.2.29__sg-aws-s3). Slice H builds against
# this stub for the S3__Source__Adapter; final ~30 min before Slice H's PR
# is a rebase to pick up Slice A's actual implementation.
# ═══════════════════════════════════════════════════════════════════════════════

from osbot_utils.type_safe.Type_Safe import Type_Safe

from sgraph_ai_service_playwright__cli.credentials.service.Sg__Aws__Session import Sg__Aws__Session


class S3__AWS__Client(Type_Safe):
    session : Sg__Aws__Session = None

    def list_buckets(self) -> list:
        raise NotImplementedError("Slice A owns this body — see v0.2.29__sg-aws-s3/")

    def list_objects(self, bucket: str, prefix: str = '', max_keys: int = 1000) -> list:
        raise NotImplementedError("Slice A owns this body — see v0.2.29__sg-aws-s3/")

    def get_object(self, bucket: str, key: str) -> bytes:
        raise NotImplementedError("Slice A owns this body — see v0.2.29__sg-aws-s3/")

    def head_object(self, bucket: str, key: str) -> dict:
        raise NotImplementedError("Slice A owns this body — see v0.2.29__sg-aws-s3/")
```

And the same shape for `aws/cloudtrail/service/CloudTrail__AWS__Client.py`:

```python
class CloudTrail__AWS__Client(Type_Safe):

    def lookup_events(self, start_time, end_time, attribute_key: str = '',
```

### F-3 (MEDIUM) — Stub verb bodies aren't there

**What the brief said** (`02__common-foundation.md §1.2`):

> Foundation ships **interface signatures only** — every method body raises `NotImplementedError("agent-X owns this")`.

And in the acceptance (`§4`):

```bash
sg aws s3 rm s3://test/foo                                          # → "SG_AWS__S3__ALLOW_MUTATIONS must be set" Rich panel
SG_AWS__S3__ALLOW_MUTATIONS=1 sg aws s3 rm s3://test/foo --yes      # → NotImplementedError (body not yet filled in) — but the gate let it through
```

**What landed:** the `Cli__<Surface>.py` skeletons are bare `app = typer.Typer(...)` declarations with no `@app.command()` definitions. The acceptance commands fail with `No such command 'rm'` (Click error) instead of the Rich mutation-gate panel.

**Fix (choose one):**

- **(A) Add stub verbs per the brief.** For each surface, register the locked verb names with bodies that raise `NotImplementedError`. ~20 minutes per surface. Slices replace the bodies — no surface re-registration needed. This is what the brief promised.

- **(B) Update the brief.** Reword Foundation §1.2 + §4 to say "Foundation ships the Typer app skeleton only; each slice registers its own verbs."

I'd pick **(A)** for two reasons: (1) it lets us actually run the Foundation acceptance commands as written; (2) it locks the verb names early, before a slice "improves" them. Worked example:

```python
# sgraph_ai_service_playwright__cli/aws/s3/cli/Cli__S3.py

@app.command()
@require_mutation_gate('SG_AWS__S3__ALLOW_MUTATIONS')
def rm(path: str = typer.Argument(..., help='s3://bucket/key to delete.'),
       yes : bool = typer.Option(False, '--yes', '-y', help='Skip confirmation.')):
    """Delete an S3 object (gated)."""
    raise NotImplementedError("Slice A owns this body — see library/dev_packs/v0.2.29__sg-aws-s3/")


# ... rest of the locked verb names per the Slice A README
```

The verb names per slice live in each sibling pack's "What you own → Verbs" table. Copy them across as stubs.

### F-4 (MEDIUM) — Tag names diverge from the brief

**Brief §3.6:**

| Tag key | Value |
|---------|-------|
| `sg:owner` | from env `SG_AWS__OWNER` (default `$USER`) |
| `sg:source` | `sg-aws-cli` |
| `sg:created-by` | `<sg-version>:<surface>:<verb>` |
| `sg:created-at` | ISO 8601 UTC |
| `sg:surface` | the surface name |

**Foundation impl (`Aws__Tagger.py`):**

```python
self._tag('sg:managed-by',  'sg-cli'),                                # was sg:source / 'sg-aws-cli'
self._tag('sg:surface',     surface.value),                           # ✓
self._tag('sg:verb',        verb),                                    # NEW — not in brief
self._tag('sg:created-by',  os.environ.get('USER', socket.gethostname())),  # was sg:owner-style value; now sg:created-by takes the user identity
self._tag('sg:created-at',  datetime.now(timezone.utc).strftime(...)) # ✓
```

So `sg:owner` and `sg:source` are gone; `sg:managed-by` and `sg:verb` are new; `sg:created-by` carries the user identity instead of the `<version>:<surface>:<verb>` triple from the brief.

The new shape is arguably cleaner (less redundancy with `sg:surface` + `sg:verb` already separate), but **slices will write tag filters expecting brief names** — e.g. Slice H's `agent-trace` correlates on `sg:session-id`; Slice D's `iam graph filter --unused` may filter on `sg:owner=$USER` per the source brief.

**Fix:** reconcile in one of two ways.

- **(A) Update the brief to match impl.** Edit `01__scope-and-architecture.md §3.6` to the new tag set. Decisions justified: `sg:managed-by` is clearer than `sg:source`; `sg:verb` adds useful correlation; `sg:owner` and `sg:created-by` collapsed because the brief was redundant.
- **(B) Update impl to match brief.** Add `sg:owner` and `sg:source` back; demote `sg:verb` to optional; encode `sg:created-by` as `<version>:<surface>:<verb>`.

I'd pick **(A)** — the impl shape is genuinely better — but the brief MUST be updated either way before slices start, because Slice D/H/G will all consult it for tag-filter logic.

### F-5 (MEDIUM) — `Source__Contract` is partly typed, partly loose

**Brief §2.5:**

```python
class Source__Contract(Type_Safe, ABC):
    def list_streams(self) -> List__Schema__Source__Stream__Ref: ...
    def tail(self, stream: Safe_Str, since: Safe_Str__Timestamp) -> Source__Stream: ...
    def query(self, q: Source__Query) -> Source__Result__Page: ...
    def stats(self, stream: Safe_Str, agg: Enum__Source__Aggregation) -> Schema__Source__Stats: ...
    def schema(self, stream: Safe_Str) -> Schema__Source__Stream__Schema: ...
```

**Foundation impl:**

```python
def list_streams(self) -> list: ...
def tail(self, stream: str, since: str) -> Source__Stream: ...
def query(self, q: Source__Query) -> Source__Result__Page: ...
def stats(self, stream: str, agg: str) -> dict: ...
def schema(self, stream: str) -> dict: ...
```

`Source__Stream`, `Source__Query`, `Source__Result__Page` exist (good). Missing: `List__Schema__Source__Stream__Ref`, `Schema__Source__Stats`, `Schema__Source__Stream__Schema`, and the `Enum__Source__Aggregation` enum.

**Why this matters:** the whole point of the contract is that Slice H can wire any source adapter (S3 from Slice A, CloudTrail from F, CloudWatch wrapper) and the REPL renders/filters them uniformly. With `stats() -> dict` and `schema() -> dict`, each adapter invents its own key layout, and Slice H is back to per-adapter `if isinstance(...)` branches.

**Fix:** add the four missing types (~30 LOC total) and tighten the contract:

```python
# aws/_shared/source_contract/Schema__Source__Stream__Ref.py
class Schema__Source__Stream__Ref(Type_Safe):
    name        : Safe_Str
    description : Safe_Str
    last_event  : Safe_Str    # ISO timestamp, may be empty

# aws/_shared/source_contract/Schema__Source__Stats.py
class Schema__Source__Stats(Type_Safe):
    stream      : Safe_Str
    aggregation : Safe_Str
    window_from : Safe_Str
    window_to   : Safe_Str
    buckets     : Dict__Source__Stats__Bucket   # or List__Source__Stats__Row

# aws/_shared/source_contract/Schema__Source__Stream__Schema.py
class Schema__Source__Stream__Schema(Type_Safe):
    stream : Safe_Str
    fields : List__Source__Field   # field_name + type_hint + nullable

# aws/_shared/source_contract/Enum__Source__Aggregation.py
class Enum__Source__Aggregation(str, Enum):
    COUNT  = 'count'
    SUM    = 'sum'
    AVG    = 'avg'
    MIN    = 'min'
    MAX    = 'max'
    UNIQUE = 'unique'

# aws/_shared/collections/List__Schema__Source__Stream__Ref.py
class List__Schema__Source__Stream__Ref(Type_Safe__List):
    expected_type = Schema__Source__Stream__Ref
```

Then tighten the ABC:

```python
def list_streams(self) -> List__Schema__Source__Stream__Ref: ...
def stats(self, stream: Safe_Str, agg: Enum__Source__Aggregation) -> Schema__Source__Stats: ...
def schema(self, stream: Safe_Str) -> Schema__Source__Stream__Schema: ...
```

Also extend `test_Source__Contract__Behaviour.py` to assert the typed returns (currently asserts `isinstance(result, dict)` — too loose).

### F-6 (LOW) — `Aws__Confirm` has no tests; `Aws__Tagger.tags_for()` returns `list` not `List__Schema__AWS__Tag`

**Coverage gap:** the other three `_shared` files have 4-6 tests each. `Aws__Confirm` has zero. The dry_run path and the yes path are both small but easy to cover:

```python
# tests/unit/sgraph_ai_service_playwright__cli/aws/_shared/test_Aws__Confirm.py
class Test__Aws__Confirm:

    def test_dry_run_returns_false_and_does_not_prompt(self, capsys):
        result = confirm_or_abort('delete me', yes=False, dry_run=True)
        assert result is False
        assert 'Dry-run' in capsys.readouterr().out or True   # rich-printed

    def test_yes_returns_true_without_prompt(self):
        result = confirm_or_abort('delete me', yes=True, dry_run=False)
        assert result is True

    def test_both_false_calls_typer_confirm(self, monkeypatch):
        seen = {'called': False}
        def fake_confirm(msg, default=False):
            seen['called'] = True
            return False
        monkeypatch.setattr('typer.confirm', fake_confirm)
        result = confirm_or_abort('delete me', yes=False, dry_run=False)
        assert seen['called'] is True
        assert result is False
```

**Type-safety nit:** `Aws__Tagger.tags_for()` returns plain `list`. The `List__Schema__AWS__Tag` collection class already exists at `aws/_shared/collections/List__Schema__AWS__Tag.py`. Two-line fix:

```python
def tags_for(self, surface, verb, session_id='') -> List__Schema__AWS__Tag:
    result = List__Schema__AWS__Tag()
    result.append(self._tag(...))
    ...
    return result
```
