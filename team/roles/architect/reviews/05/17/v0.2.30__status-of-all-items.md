## Issues introduced during the sweep (regressions)

### Regression-1 — `FALLBACK_REGION` no longer importable (6 broken test files)

**Source**: dev commit `9f830a93` (Open-3: `current_region` → `Aws__Region__Resolver`) removed the `FALLBACK_REGION` constant from the AWS-client modules but didn't update the 6 test files that import it.

```
tests/unit/sgraph_ai_service_playwright__cli/aws/acm/service/test_ACM__AWS__Client.py
tests/unit/sgraph_ai_service_playwright__cli/aws/bedrock/cli/test_Cli__Bedrock__check_and_setup.py
tests/unit/sgraph_ai_service_playwright__cli/aws/bedrock/service/test_Bedrock__Chat__Flow.py
tests/unit/sgraph_ai_service_playwright__cli/aws/bedrock/service/test_Bedrock__Control__AWS__Client.py
tests/unit/sgraph_ai_service_playwright__cli/aws/bedrock/service/test_Bedrock__Preflight.py
tests/unit/sgraph_ai_service_playwright__cli/aws/bedrock/service/test_Bedrock__Runtime__AWS__Client.py
```

All 6 fail at COLLECTION time with `ImportError: cannot import name 'FALLBACK_REGION'`. Fix is mechanical (drop the import, inline the constant where needed) — ~15 minutes.

### Regression-2 — 19 S3 test failures (`put_object` no longer returns bool)

**Source**: dev commit `0698e48b` (Open-4 Part A swallow sweep for S3) changed `S3__AWS__Client.put_object` etc. to let `ClientError` propagate instead of swallow → returning `None` on success. The tests still assert `assert ok is True`. Pre-existing fallout; not fixed yet.

```
tests/unit/sgraph_ai_service_playwright__cli/aws/s3/service/test_S3__Mutation__Gate.py::TestConditionalPut::test_put_with_matching_etag_succeeds (and similar)
```
