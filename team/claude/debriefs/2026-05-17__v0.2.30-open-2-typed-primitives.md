## 6. Pattern established

Every `Safe_Str__*` primitive for AWS surface fields follows:

```python
import re
from osbot_utils.type_safe.safe_types.Safe_Str import Safe_Str
from osbot_utils.type_safe.safe_types.enums.Enum__Safe_Str__Regex_Mode import Enum__Safe_Str__Regex_Mode

class Safe_Str__Foo__Bar(Safe_Str):
    regex      = re.compile(r'[^ALLOWED_CHARS]')
    regex_mode = Enum__Safe_Str__Regex_Mode.REPLACE
    allow_empty = True
```

REPLACE mode: forbidden chars are stripped (not rejected). `allow_empty = True`: empty-string default is valid.
`Safe_Str` subclasses `str` so all existing `str` operations work without coercion at call sites.
