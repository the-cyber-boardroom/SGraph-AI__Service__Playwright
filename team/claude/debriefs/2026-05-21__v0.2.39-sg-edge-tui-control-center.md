## How it honours the separation guide

- **No TUI-exclusive capability.** Each key (`n`/`N`/`u`/`g`/`S`/`X`) is one
  `source.*` call = one `sg edge local *` verb. The screen owns no logic.
- **Capability-gated, rendered (rule 5).** `source.can_act()` → local `True`, AWS
  `False`; on AWS the action panel renders greyed and a keypress is a `notify` no-op
  (a pilot test asserts the debug log stays empty — nothing performed).
- **Preview before mutate (rule 6).** A pure `request_prediction` + the preview pane;
  the native home is `request` (already a simulate) + new `--dry-run` flags.
- **Head-less ≠ CLI (rule 3).** Piped → the read-only card + a footer listing the
  native command for each action; it does **not** mutate.
- **Debug Panel is the proof.** Every action wraps a `log_event('stack', …)` so the
  panel shows the backend call under each keypress.

## Decisions taken (owner said "proceed unless you need a decision")

- **`?`/`e`/`t` added locally** on the Control Center (not forked into the shared
  `Tui__App`) — lift them into `cli/tui` in a coordinated shared-lib change later.
- **Debug logging wrapped in the screen** (not injected into the source) — keeps the
  source pure; the screen logs the actual `Local__Edge__Stack` method it invoked.
- **`request` is gated by `can_act()` too** — correcting the brief: `AWS_Source.request()`
  *raises* (Slice 5), so an ungated `g` on `--target aws` would crash. Gating it is
  consistent with rule 5 and a no-op change on local.

## Gotchas the next session will hit

- **Do not name a screen method `run_action`** — it shadows Textual `App.run_action`
  (the binding dispatcher) and every keypress fails with a TypeError. Renamed to
  `perform`. **Good failure**, caught by the pilot.
- **`Input` focus eats action keys.** The screen focuses the DataTable on mount so
  `n`/`g`/… fire; type a name in the Input then Enter (= register) or Tab back to the
  table. A finding worth noting for the eventual canonical app: a name-prompt modal on
  `n` would be smoother than a persistent Input.
